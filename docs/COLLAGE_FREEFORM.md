## 동작

- 자유형 사진은 드래그로 이동, 두 손가락 또는 오른쪽 아래 손잡이로 비율을 유지하며 확대·축소한다. 사진을 잃어버리지 않도록 전체 프레임은 캔버스 안으로 제한한다.
- `자르기`에서는 사진 내부 드래그·핀치 및 확대 슬라이더로 구도를 바꾼다. 네 변의 손잡이는 프레임을 자유 비율로 자른다. 원본·1:1·4:5·3:2·9:16 비율을 제공하고 `원본`은 사진 전체가 보이도록 확대·이동도 초기화한다. `완료` 또는 시스템 뒤로 가기로 이동 모드로 돌아온다. 잘린 원본 데이터를 삭제하지 않는다.
- `앞으로`/`뒤로`는 겹친 사진을 한 단계씩 이동한다. 하단 사진 목록으로 가려진 사진도 선택한다. 레이어 순서는 원본 사진 순서와 별도로 저장하여 원본 캔버스 비율이 바뀌지 않게 한다.
- 사진 추가·교체·삭제, 회전·반전, 배경·모서리·테두리, 실행 취소/다시 실행, 화면 재생성 복원을 지원한다. 자유형에서 추가·교체하는 사진도 전체 원본 비율을 사용한다. 교체 시 중심 위치·레이어를 유지하며 새 사진 비율에 맞게 프레임을 바꾼다. 이동/크기 조절/자르기 제스처 하나는 실행 취소 한 단계다.
- 자유형 사진 선택 도구의 `원본 복원`은 현재 사진의 크롭과 내부 확대·이동을 지우고 전체 사진을 보여 준다. `초기화`는 회전·반전도 초기화한다. 회전, 캔버스 비율 변경, 원본 비율 캔버스에서 첫 사진 교체·삭제 시에도 나머지 프레임의 화면상 비율을 유지한다.
- 기존 최대 9장 제한, 홈으로 돌아갈 때 선택 초기화, 원본 보존, 오프라인 처리, 새 JPEG 저장을 유지한다. 자유형에서는 칸 사이 간격·바깥 여백 대신 각 사진 위치를 직접 조절한다.
