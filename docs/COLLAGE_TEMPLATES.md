# 콜라주 템플릿·디자인 확장

2026-10-29 KST

현재 공통 편집 화면·사진 보정·수동 보관함 사용법과 후속 검증은 [REA 제안 적용](COLLAGE_GRIDART_APPLIED.md)을 참조한다. 아래 기존 검증·전달 기록은 당시 빌드에 대한 기록이다.

## 구현된 동작

- 콜라주 첫 화면에서 템플릿을 먼저 고르고, 각 사진 칸의 +를 누르면 위 미리보기와 아래 갤러리를 함께 표시한다. 사진을 누르면 현재 칸에 반영하고 체크 또는 뒤로 가기로 갤러리를 닫는다.
- 60종(10계열 각 6종)을 앱에 포함한다. 기본 배치는 잠그고 배치 편집을 켜면 사진틀·글자·장식을 수정한다.
- 일부 사진 칸이 비어 있어도 저장한다. 빈 사진틀·테두리·선택 표시는 출력에서 제외하며, 독립 배경·글자·장식은 남긴다. 사진이 없거나 선택한 사진의 읽기가 실패하면 저장하지 않는다.
- 사진틀 최대 15개, 비정형 프레임, 확장 배경, 한글 글자, 임의 회전, 자석 및 다중 정렬을 제공한다.
- 원본 보존, 오프라인, JPEG 최대 긴 변 4096px, 홈 복귀 초기화와 버전 1.2.1 (4)을 유지한다.

## 참고와 자산 정책

사용자가 제공한 GridArt 화면, https://www.canva.com/photo-collages/templates/ , https://www.adobe.com/express/templates/photo-collage , https://www.befunky.com/create/collage/ 의 구도·분류를 참고한다. 배치·장식은 코드로 직접 제작한다. 글꼴은 Google Fonts의 원본 파일과 OFL을 함께 보관한다. 참고 화면의 인물 사진·유료 그래픽은 앱 자산에 포함하지 않는다.

## 사용 방법

1. 홈 → 콜라주 → `템플릿 · 60가지 디자인`에서 시작한다. 일반 사진 선택으로 시작해도 같은 공통 편집 도구를 사용한다.
2. 스타일·사진 칸 수·비율 필터로 템플릿을 찾는다. 목록의 풍경은 코드로 만든 예시 그림이며 사용자의 사진을 자동으로 읽어 넣지 않는다.
3. 사진 칸을 누르면 위 미리보기와 아래 4열 갤러리가 함께 나온다. 현재 칸은 파란 테두리로 표시한다. 사진을 누르면 선택한 칸을 채우거나 교체한다. 기본으로 다음 빈칸을 선택하며 `다음 빈칸으로`를 끄면 현재 칸을 유지한다. `빈칸 한번에 채우기`는 남은 빈칸 수만큼 골라 채운다. 체크 또는 뒤로 가기로 갤러리를 닫아도 적용한 사진은 유지한다. 읽을 수 없는 사진을 고르면 갤러리 안에서 오류를 안내하며 이전 사진은 유지한다.
4. 기본 배치 잠금 상태에서도 사진 내부 드래그·핀치, 교체·비우기, 문구·배경·색상을 편집한다. `배치 편집`을 켜면 사진틀·글자·장식의 이동·크기·임의 회전·삭제·겹침 순서를 편집한다. 잠금을 다시 켜도 수정한 배치를 유지한다.
5. `자석·정렬`에서 자석을 켜거나 끄고, 다중 선택을 켠 뒤 요소 목록에서 정렬할 대상을 고른다. 한 개는 캔버스, 여러 개는 선택 영역을 기준으로 정렬한다. 간격 맞춤에는 3개 이상이 필요하다. 자석은 화면상의 중심·가장자리와 회전 15도 간격에 반응한다.
6. 빈칸은 채우지 않아도 저장할 수 있다. +와 편집 테두리, 빈 칸의 사진틀 여백은 출력에서 제외하고 배경·독립 글자·장식은 유지한다. 사진이 하나도 없거나 선택한 원본을 읽지 못하면 저장하지 않는다.

## 렌더링·호환성

- 사진틀은 사각형·둥근 사각형·원·타원·하트·별·삼각형·마름모·육각형·아치·사선·물결·찢어진 종이를 지원한다. 개별 제어점을 그리는 벡터 편집기는 아니다.
- 배경은 단색/직접 HEX 색상, 두 색 그라데이션/각도, 종이·린넨·도트·격자·체크·줄무늬, 사진/흐림을 지원한다. 글자는 한글 4종 폰트, 여러 줄, 정렬·색·크기·외곽선·그림자를 지원한다.
- `CollageJob`은 고유 요소 ID, 빈 사진 URI, 사진틀 모양·회전·여백, 글자·장식·배경·템플릿·잠금 상태를 포함한다. 기존 JSON에 `design`이 없어도 이전 기본값으로 복원한다. 비트맵과 실행 취소 사진 데이터를 Bundle/JSON에 넣지 않는다.
- 일반 갤러리와 하단 갤러리는 같은 앨범·권한·페이지 로딩·썸네일을 사용한다. 하단 갤러리는 편집기 테마와 맞추고, 다중 선택 배지 없이 현재 칸에 바로 반영한다.
- 사진/배경/글자/장식의 기하·그리기 함수와 레이어 순서는 미리보기와 JPEG가 공유한다. ‘원본’ 캔버스는 첫 번째 채워진 사진 비율을 사용하며, 비율 변경 시 전체 디자인의 화면상 비율을 유지한다. 사진 추가·교체·삭제도 이 기준에 맞춘다.
- 미리보기 예산은 기기 힙 1/4, 전체 최대 128MiB/개별 최대 64MiB를 분배한다. 흐림은 최대 320px 작업 비트맵으로 처리한다. 저장 시 사진은 필요한 출력 크기로 한 장씩 읽고 해제한다. 최대 4096px와 bilinear 리사이즈를 유지한다.

### 테스트 환경

기존 공유 ADB 서버(5037)는 같은 AVD를 unauthorized로 표시했다. 공유 서버를 재시작하지 않고 테스트 전용 서버(5038)에서 연결했을 때 device 상태를 확인했다. 전용 `SBPhotoTemplate_QA` AVD를 프로젝트 `build/`에 만들었으며 실제 휴대폰에는 설치하거나 명령을 실행하지 않았다.

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug --console=plain
adb -P 5038 -s emulator-5554 install -r app/build/outputs/apk/debug/app-debug.apk
adb -P 5038 -s emulator-5554 install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -P 5038 -s emulator-5554 shell pm grant com.sb.phototool android.permission.READ_MEDIA_IMAGES
adb -P 5038 -s emulator-5554 shell pm grant com.sb.phototool android.permission.POST_NOTIFICATIONS
adb -P 5038 -s emulator-5554 shell am instrument -w -r -e class com.sb.phototool.media.CollageTemplateRenderTest,com.sb.phototool.ui.collage.CollageDesignInteractionTest,com.sb.phototool.CollageNavigationTest,com.sb.phototool.ui.collage.CollageEditorTest,com.sb.phototool.media.CollageExportTest com.sb.phototool.test/androidx.test.runner.AndroidJUnitRunner
```

`emulator-5554`와 5038은 이번 실행의 값이다. 재현할 때 `devices -l`로 전용 AVD를 확인한다. 계측 테스트는 생성한 합성 사진 URI만 정리한다.
