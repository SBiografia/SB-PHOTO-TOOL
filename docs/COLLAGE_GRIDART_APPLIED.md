2026-10-29 KST

사용자 요청에 따라 [REA 분석](research/gridart-2.454.225-20261029/REPORT.md)의 SB 적용 제안을 구현했다. 참조 앱의 자산·코드·필터 LUT를 복사하지 않고 기존 Kotlin/Compose 문서 모델과 Android Canvas 렌더러를 확장했다. 분석 문서는 당시 소스·정적 근거의 기록으로 유지한다.

### 편집 화면 수정 — 2026-11-04 KST

- 콜라주 편집기 하단의 선택 사진 썸네일 목록을 제거했다. 하단 도구 패널은 고정 높이 대신 내용에 맞춰 표시하여 목록이 차지하던 공간도 줄인다.
- 사진 선택은 캔버스의 사진 또는 `요소 선택` 도구를 이용한다. 사진 교체·추가용 갤러리는 유지한다.
- 공통 도구와 사진 선택 후 도구에 기능별 아이콘을 추가했다. 아이콘 아래에 기존 이름을 표시하며 버튼의 비활성 조건과 동작은 유지한다.
- 캔버스 비율과 사진틀 자르기 비율은 숫자와 해당 비율의 직사각형을 함께 표시한다. 캔버스의 `원본` 도형은 첫 사진의 비율을 사용한다. 비율 선택 항목은 가로로 스크롤한다.
- 레이아웃의 `전체/기본/강조/모자이크` 분류 탭을 제거하고 모든 레이아웃을 기존 순서로 표시한다.
- 여백의 바깥 여백·사진 사이 간격·둥근 모서리에 아이콘을 추가했다. 3dp 트랙과 14dp 손잡이를 사용하고, 조작 영역은 최소 48dp로 유지한다. 행 사이 추가 간격을 없애고 모두 제거 버튼을 제목 옆 아이콘으로 옮겨 패널 높이를 줄였다.
- 도구 UI 수정 당시에는 소스 비교와 로컬 Compose 의존성으로만 정적으로 확인하고 빌드·APK 생성·실행 테스트는 하지 않았다. 이후 사진 재선택·회전 수정에서 수행한 컴파일·단위 테스트는 다음 절을 따른다. 아래 이전 APK·계측 기록과 구분한다.

### 사진 재선택·회전 수정 — 2026-11-04 KST

- 선택한 사진을 다시 한 번 누르면 선택과 개별 편집 메뉴를 해제한다. 캔버스 터치, 접근성 클릭, 요소 선택 목록에 같은 규칙을 적용하며 잠근 사진도 선택 해제할 수 있다. 선택 해제 시 교환 대기도 취소한다.
- 캔버스 터치는 손가락을 떼고 이동·다중 터치가 없을 때 해제한다. 기존 사진 이중 탭의 맞춤/채움과 드래그·핀치·길게 눌러 교환하는 경로는 유지한다. 메뉴 표시로 캔버스 크기가 바뀌어도 진행 중인 제스처를 취소하지 않으며, 제스처 시작 시의 크기를 사용한다.
- `요소 각도`를 `회전`으로 바꾸고 0~360도와 도 기호를 표시한다. 기존 음수 각도는 같은 방향의 양수 각도로 보여 주며 360도 끝점은 슬라이더 오른쪽에 유지한다.
- 0·90·180·270·360도에서 3도 이내로 들어오면 정확한 각도에 붙는다. 붙은 뒤에는 5도 이내까지 유지하고 더 움직이면 미세 조정으로 돌아간다. 기준점에 진입할 때만 짧은 진동 피드백을 요청한다. 글자 편집의 회전 슬라이더도 같은 조절을 사용한다.
- 변경 소스: `ui/collage/CollageDesignStudio.kt`, `CollageDesignCanvas.kt`, `CollageDesignControls.kt`, `CollageControlComponents.kt`, `CollageRotation.kt`. 회전 검증은 `CollageRotationTest.kt`에 추가했다.
- 검증: Kotlin 앱·단위 테스트 소스 컴파일 성공. `CollageRotationTest` 3개, `CollageDesignTest` 8개, `CollageEditingTest` 9개, `CollageEditorStateTest` 2개로 총 22개 통과, 실패·오류·건너뜀 0개. 정확한 각도·붙음/해제 경계·기존 부호 각도·편집 상태와 Undo를 검사했다. 선택 해제와 기존 터치 경로는 소스 비교로 확인했으며 실기기 터치·진동·계측 테스트는 실행하지 않았다.

### 사진 도구 재구성 — 2026-11-05 KST

- 공통 콜라주 도구에서 모양을 제거하고 사진 도구의 `사진틀 모양`으로 제공한다. 사진틀 종류는 줄바꿈 없이 한 행에서 가로로 스크롤한다. 여러 사진을 선택한 경우에도 잠기지 않은 사진에 모양을 적용할 수 있다.
- 콜라주의 모든 슬라이더를 여백·모서리와 같은 공통 컴포넌트로 통일했다. 3dp 트랙·14dp 손잡이를 사용하며 조작 행은 최소 48dp를 유지한다. 사진 필터·보정, 정밀 조정, 배경, 글자, 사진틀, 테두리, 장식, 회전에 함께 적용한다.
- 사진을 선택한 기본 도구에는 회전 슬라이더를 표시하지 않는다. `회전/반전` 메뉴에 90도 회전, 0~360도 미세 회전, 좌우 반전, 상하 반전을 모았다. 90도 버튼과 슬라이더 각도 표시를 연결했고 기존 회전 스냅·진동 및 Undo 연결을 유지한다.

### 다중 선택·레이아웃 손잡이 수정 — 2026-11-05 KST

- 별도의 `자석·정렬`과 `요소 선택` 메뉴를 제거했다. 사진을 직접 움직일 때 중심·가장자리에 붙는 동작과 회전 안내는 유지한다. 이전 문서의 자석 설정 필드는 읽을 수 있도록 남기되, 현재 편집기에서는 자동 맞춤을 항상 사용한다.
- 사진 도구의 `완료` 왼쪽에 `다중 선택` 버튼을 배치했다. 켜진 상태는 파란 음영과 글자색으로 표시한다. 사진을 누르면 선택·해제하며 여러 장에서도 사진 도구를 계속 표시한다. 버튼을 끄면 첫 선택 사진 한 장을 유지하고, 완료로 선택과 다중 선택 모드를 끝낸다. 마지막 사진을 해제해도 버튼과 완료는 남는다.
- 합의한 동작은 **다중 선택 이후의 조작만 함께 적용**하는 것이다. 사진마다 다른 기존 필터·대비·위치 등을 첫 사진에서 복사하지 않는다. 필터·보정, 회전·반전, 사진틀 모양·색·여백, 맞춤/채움, 원본 복원, 정밀 조정의 위치·확대를 선택한 사진들에 연결했다. 잠긴 사진은 편집에서 제외하며 잠금 해제는 별도로 함께 할 수 있다.
- 90도 회전·반전·위치 이동·확대 버튼은 각 사진의 현재 상태에서 동작한다. 각도·확대·보정 슬라이더와 사진틀 설정은 사용자가 새로 지정한 해당 항목만 같은 값으로 적용한다. 보정 취소는 선택 사진 전체를 이전 상태로 복원하며 적용·드래그는 한 번의 Undo로 되돌린다.
- 레이아웃 타원 손잡이는 첫 터치를 직접 소비한 뒤 드래그를 처리하도록 바꿨다. 부모 캔버스의 사진 이동·선택 해제와 경합하지 않게 했고, 드래그 시작 시 현재 칸 배치·바깥 여백으로 이동량을 계산한다. 다중 선택 중에는 손잡이를 숨기며, 잠긴 이웃 사진의 칸까지 바뀌는 경계도 표시하지 않는다. 너비·높이 변경을 한 번의 Undo로 되돌린다.
