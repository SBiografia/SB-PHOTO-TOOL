# SB PHOTO TOOL

Android 10 이상에서 동작하는 오프라인 사진 도구입니다. 접근을 허용한 기기 갤러리와 선택한 폴더에서 사진을 읽고, 서버 업로드·계정·광고 SDK 없이 기기 안에서 처리합니다.

## 포함 기능

- **콜라주**: 최대 15장, 레이아웃/자유형 전환, 사진 수별 기본·강조·모자이크 배치, 자유형의 원본 비율 배치·원본 복원·이동·확대축소·자르기·겹침 순서, 칸 크기 조절, 교체·위치 교환·회전·반전, 실행 취소/다시 실행, 비율·여백·모서리·테두리 설정. 공통 하단 도구에서 비정형 사진틀·임의 회전·자석·다중 정렬, 확장 배경·한글 글자·장식을 편집합니다. 사진별 잠금·맞춤/채움·정밀 이동·필터 6종·밝기/대비/채도, 글자 스타일·자간·행간을 지원하며 미리보기와 같은 렌더러로 새 JPEG를 저장합니다. 마지막에 쓴 비율·레이아웃(사진 장수별)·바깥 여백·사진 간격·모서리·배경색·테두리를 기억해 다음 콜라주도 같은 설정으로 시작합니다.
- **콜라주 템플릿**: 첫 화면의 `템플릿`에서 10계열 60종을 선택합니다. 각 칸의 +를 누르면 위 미리보기와 아래 4열 갤러리에서 사진을 넣습니다. 기본 배치를 잠그며 `배치 편집`을 켜면 사진틀·글자·장식을 이동·회전·크기 조절할 수 있습니다. 다음 빈칸 자동 이동·빈칸 일괄 채우기를 지원합니다. 사진을 유지하며 템플릿을 바꾸고, 남는 사진은 자유 배치로 추가합니다. 일부 칸만 채워도 저장하며 빈 사진틀과 편집 표시는 출력에서 제외합니다.
- **사진 압축**: 한 번에 최대 100장, 현재 앨범·필터 전체 선택(정렬 순서대로 최대 100장), 전체 선택 옆 전체 해제(1장 이상 선택 시 활성화), 최근 저장순/용량 큰 순 정렬과 용량 표시, 선택 사진 미리보기·제외, 여러 사진/폴더 처리, 용량·해상도 프리셋, JPEG/PNG/WebP 및 EXIF 설정, ‘1장 테스트’ 원본/결과 비교와 실측 용량, 완료 시 전체 용량 비교와 성공한 원본의 선택적 별도 보관 폴더 이동
- **사진 분할**: 큰 사진 위에서 자르기 영역 이동·네 변 손잡이 조절, 격자 프리셋·가로/세로 1~10 직접 입력, 정사각형 조각과 저장 순서 번호, Fit/Fill·배경·출력 설정
- **GIF · MP4 만들기**: 사진 재생 미리보기, 순서 이동·반전·제외·표시 시간 조절, GIF 또는 무음 MP4 출력 선택, 해상도·GIF 반복 설정. 동영상 입력은 지원하지 않습니다.
- **자체 사진 선택**: 앨범 목록, 날짜별 3열 사진·즐겨찾기, 선택 순번, 길게 누른 후 드래그 선택, 선택 사진 모음. 콜라주 15장·그리드 1장·압축 및 GIF/MP4 100장 제한을 선택 시 적용합니다. 템플릿의 하단 갤러리는 한 번 누를 때 현재 사진 칸에 반영합니다.
- **설정 · 진단 로그**: 사진 선택·미리보기·예기치 않은 종료의 앱 내부 기록 확인, 복사·공유·삭제

## 저장 및 개인정보

- 압축 완료 후 `원본 N장 별도 보관 폴더로 이동`을 직접 누르고 시스템의 파일 수정 확인창에서 승인하면, 압축에 성공한 원본을 같은 저장장치의 `Pictures/SB PHOTO TOOL/compress_original`로 모읍니다. 원본 바이트·EXIF를 유지하며 이름 충돌은 MediaStore의 고유 파일명 처리로 구분합니다. 사용자가 보관 폴더에서 삭제·백업 여부를 결정합니다. 압축본은 `Pictures/SB PHOTO TOOL/Compress`에 저장합니다. 원본 이동은 Android 11 이상에서 지원하며, 접근 불가·미지원 공급자의 사진은 제외 안내합니다.
- 이미지 결과는 `Pictures/SB PHOTO TOOL/{Collage,Compress,Split,GIF}`에, MP4는 `Movies/SB PHOTO TOOL` 아래에 저장됩니다.
- 압축 결과만 실행 시 촬영 정보 보존 또는 제거를 선택할 수 있습니다. 압축은 원본 형식·파일명·확장자를 유지하며 EXIF·GPS 등 메타데이터 블록을 보존합니다(출력 치수는 갱신). 중복 이름은 하위 폴더로 분리합니다. 실제 수정일과 미디어 DB 촬영일도 보존·재검증하며 실패나 지원 제한을 알립니다. 자세한 범위는 [압축 메타데이터](docs/COMPRESSION_METADATA.md)를 참고하세요. 새 콜라주·분할·GIF는 원본 위치 정보를 이어받지 않습니다.
- 자체 갤러리는 기기의 사진 읽기 권한을 요청합니다. Android 14 이상에서는 일부 사진만 허용해도 사용할 수 있으며 선택 화면에서 허용 사진을 추가할 수 있습니다. 압축 폴더는 기존 시스템 폴더 선택 권한을 사용합니다. 인터넷 권한은 없습니다.
- 별도의 장기 사진·결과 이력은 자동으로 보관하지 않습니다. 원본 폴더 이동을 위해 최근 압축 작업의 성공한 원본 목록만 앱 내부에 보관합니다. 새 압축을 시작할 때 목록을 초기화하고 완료 시 성공한 원본으로 갱신하며, 늦게 끝난 이전 작업은 이 목록을 바꾸지 않습니다. 원본·압축본의 대응표나 사진 사본은 만들지 않습니다. `보관함`에서 직접 저장한 콜라주 초안·사용자 템플릿은 앱 내부에 최대 30개 보관합니다. 초안은 원본 사진 바이트를 별도로 복사하며 템플릿에는 사진을 넣지 않습니다. 콜라주를 새로 열 때 시작할 비율·레이아웃·여백·배경색·테두리만 앱 내부 설정값으로 기억하며 사진 URI·사진별 확대·회전·보정값은 저장하지 않습니다. 앱 데이터 삭제·제거 시 보관함과 기억한 설정도 삭제됩니다.
- 홈으로 돌아가면 모든 기능의 사진 선택과 콜라주 작업 내용을 초기화합니다. 기억한 콜라주 설정값(비율·레이아웃·여백 등)은 이 초기화와 별개로 유지됩니다. 편집 중 재선택을 취소하면 기존 작업을 유지합니다. 자체 갤러리의 선택 목록과 큰 압축 목록은 화면 재생성 동안 ViewModel로 유지하고, 프로세스가 종료되면 다시 선택합니다. 다시 편집할 콜라주는 홈으로 나가기 전에 `보관함 → 초안 저장`을 사용합니다. 보관함의 명시적 저장 항목은 홈 복귀 후에도 유지됩니다.
- 진단 로그는 앱 내부에만 보관하며 사진 URI·사용자 콘텐츠·인증 정보는 기록하지 않습니다. Android 전체 로그캣은 일반 앱 권한으로 읽지 않습니다.

## 개발 및 검증

```powershell
.\gradlew.bat :app:testDebugUnitTest
.\gradlew.bat :app:lintDebug
.\gradlew.bat :app:assembleDebug :app:assembleDebugAndroidTest
.\gradlew.bat :app:assembleRelease
```

빌드는 Android Studio JBR을 사용하도록 프로젝트에 설정되어 있으며, `minSdk 29`, `targetSdk 36`입니다.

변경 범위와 검증 근거는 [REA 제안 적용](docs/COLLAGE_GRIDART_APPLIED.md), [템플릿·디자인 확장](docs/COLLAGE_TEMPLATES.md), [자유형·레이아웃 확장](docs/COLLAGE_FREEFORM.md), [콜라주 설정 기억](docs/COLLAGE_SETTINGS_MEMORY.md), [콜라주 UX 기록](docs/COLLAGE_UX.md), [그리드·압축·GIF UX 기록](docs/TOOLS_UX.md), [고화질 미리보기·자체 갤러리 기록](docs/GALLERY_PREVIEW.md)에 있습니다. 현재 소스 버전은 `1.2.1 (4)`이며 테스트 APK는 Play 스토어 서명과 별개입니다.

압축의 100장 전체 선택·용량순 정렬 동작과 검증은 [압축 선택·정렬 기록](docs/COMPRESSION_SELECTION.md)을 참고하세요.

압축 완료 후 선택적으로 원본을 모으는 흐름과 검증 범위는 [압축 원본 별도 보관 폴더 이동](docs/COMPRESSION_ORIGINAL_ARCHIVE.md)을 참고하세요. 이전 휴지통 방식의 구현·배포·실사용 보고는 [과거 휴지통 이동 기록](docs/COMPRESSION_TRASH.md)에 보관합니다.

## 알려진 작업 경계

- 템플릿과 기본 장식은 앱에 포함한 자체 제작 디자인이며, 글꼴 4종은 라이선스와 함께 오프라인으로 제공합니다. 인터넷에서 새 템플릿을 다운로드하지 않습니다. 사용자 템플릿은 이 기기의 보관함에 직접 저장할 수 있습니다. 템플릿의 빈칸도 최대 15개 사진틀 제한에 포함하며 배경 사진은 별도입니다.
- 자체 갤러리는 기기 MediaStore에 있는 접근 가능한 사진을 기본 최근 저장순으로 보여 줍니다. 압축에서는 용량 큰 순으로 바꿀 수 있습니다. 다운로드하지 않은 클라우드 전용 사진은 표시하지 않습니다. 즐겨찾기는 Android 11 이상에서 기기 미디어 DB의 표시를 따릅니다.
- 콜라주·그리드 미리보기는 원본에서 직접 읽으며 긴 변 최대 8192px, 기기 힙의 1/4(전체 최대 128MiB, 개별 최대 64MiB)을 사용합니다. 여러 사진은 이 예산을 나눕니다. 초고화소 사진을 무제한 원본 크기로 올리는 방식은 아니며 저장 해상도 설정과 별개입니다.
- GIF와 MP4는 음성을 포함하지 않습니다. MP4 출력은 12 FPS이며 GIF 반복 횟수 설정은 적용하지 않습니다.
- GIF 사진 미리보기는 항상 반복합니다. 출력 UI의 긴 변은 160~1920px이며 메모리·저장 공간에 위험한 조합은 실행 전 안내합니다.
- 압축의 %는 해상도 비율입니다. 최대 용량과 촬영 정보 보존이 충돌하면 실측 테스트 및 완료 메시지로 목표 용량 초과를 알립니다.
- 그리드 조각은 정사각형입니다. 게시 서비스의 프로필 표시 비율이나 임의의 4열 배치를 보장하지 않습니다.
- PNG는 무손실 형식이라 아주 작은 최대 용량을 보장하지 못할 수 있습니다. 압축은 원본 형식을 유지하며, 맞출 수 없는 용량은 제한을 늘리도록 안내합니다.
