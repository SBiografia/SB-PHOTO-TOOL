# Third-party notices

This project uses Square's `gifencoder` (Apache-2.0) for GIF89a encoding.
The dependency is used as a small pure-Java encoder; no FFmpeg binaries are bundled.

Offline collage fonts are bundled under the SIL Open Font License 1.1:

- Nanum Gothic and Nanum Myeongjo: NHN Corporation and respective project authors.
- Nanum Pen Script: NHN Corporation and respective project authors.
- Jua: The Jua Project Authors.

The unmodified font files, exact copyright/OFL notices, pinned Google Fonts source URLs,
and SHA-256 digests are in `app/src/main/assets/fonts/` (`sources.json` and each `*-OFL.txt`).
Collage templates, vector decorations, patterns, and preview landscape drawings are authored
in this project. Reference app screenshots and personal photos are not bundled.
